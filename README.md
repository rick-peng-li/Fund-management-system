# 资金管理系统前端项目

这是一个使用 React + TypeScript + Tailwind CSS 构建的现代化资金管理系统前端项目。页面设计简洁直观，具有良好的响应式布局，完美适配 PC 和移动端设备。

## 🌟 项目介绍

本项目旨在为用户提供全面的资金管理功能，核心特性包括：

### 1. 账户概览
- **总资产**：展示用户总资产，包含“充值”和“提现”功能入口。
- **可用余额**：展示随时可用的资金，包含“转账”和“投资”功能入口。
- **冻结资金**：展示投资中或审核中的资金，包含“查看详情”入口。
- **交互反馈**：所有功能按钮点击时均会有友好的 Toast 提示。

### 2. 资产走势图
- **多维度查看**：支持按周、月、季、年四个时间维度查看资产变化趋势。
- **响应式图表**：图表区域高度自适应设备屏幕（移动端自动调整高度）。
- **状态切换**：切换时间周期时提供即时反馈提示。

### 3. 交易记录管理
- **高级筛选**：支持按“交易类型”（充值/提现/转账）、“交易状态”（成功/处理中/失败）和“时间范围”进行组合筛选。
- **实时搜索**：提供搜索框，支持键盘回车搜索交易记录。
- **数据展示**：清晰的表格展示，包含交易编号、时间、类型、金额（不同颜色区分收支）、交易方及状态标签。
- **分页功能**：底部集成简洁的分页控件。

### 4. 技术亮点
- **技术栈**：React 18, TypeScript, Vite, Tailwind CSS。
- **响应式设计**：
  - PC端：三栏卡片布局，横向筛选栏。
  - 移动端：单栏卡片流式布局，纵向筛选栏，优化触控体验。
- **样式方案**：全量使用 Tailwind CSS utility classes，无额外 CSS 文件依赖，加载速度快。

## 🚀 快速开始

你可以选择使用 Docker 快速部署，或者使用 npm 本地启动。

### 方式一：使用 Docker 启动（推荐）

适合快速预览和部署，无需配置本地 Node.js 环境。

**前置要求**：
- Docker
- Docker Compose

**启动命令**：
在项目根目录下执行：

```bash
docker-compose up -d --build
```

启动成功后，访问 **http://localhost:3000** 即可查看页面。

### 方式二：使用 npm 本地启动

适合开发调试。

**前置要求**：
- Node.js (建议 v18+)
- npm 或 yarn/pnpm

**启动步骤**：

1. **进入前端目录**
   ```bash
   cd frontend
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

4. **访问页面**
   开发服务器启动后，通常访问 **http://localhost:5173**（具体端口请查看终端输出）。

## ⚠️ 注意事项

- 本项目为纯前端演示项目，部分功能（如充值、提现、筛选等）仅展示交互提示，未对接真实后端接口。
- 移动端适配基于 CSS Media Queries 实现，建议使用 Chrome 开发者工具的移动端模式进行预览。
